# GeoProspect

GeoProspect is an independent public-data mineral-prospectivity research project.

The project is currently in **Stage 0 — Project Bootstrap and Feasibility Gate**. Stage 1 and all model, API, frontend, PostGIS and agent work remain blocked until a documented GO decision is issued.

See `docs/stage0/STAGE0_SCOPE.md` and `docs/stage0/STAGE1_BLOCKED.md` once the Stage 0 control pull request is merged.
